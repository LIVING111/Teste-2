# Template Premium para Restaurante

Projeto comercial em HTML, CSS e JavaScript puro.

## Como personalizar
1. Edite `js/config.js` com nome, WhatsApp, endereço, redes sociais e imagens.
2. Edite `js/menu.js` para alterar produtos, preços, categorias e imagens.
3. Substitua arquivos em `/img` se quiser usar imagens locais.

## Hospedagem
Funciona em GitHub Pages, Netlify, Vercel, Hostinger ou qualquer hospedagem estática.

## WhatsApp
Configure `whatsapp` em `js/config.js` usando DDI + DDD + número.
Exemplo: `5598999999999`.

## Observação
As imagens de demonstração usam links externos do Unsplash. Para vender a clientes, substitua por fotos reais do estabelecimento.
